## ✨ Особенности

### 🎯 Основной функционал
- **📱 Адаптивный дизайн** - идеально выглядит на всех устройствах
- **🎠 Интерактивные карусели** - бесконечная прокрутка портфолио
- **💬 Система отзывов** - верифицированные отзывы с ссылками на клиентов
- **🖼️ Модальные окна** - просмотр работ в полноэкранном режиме
- **🎨 Плавные анимации** - современные переходы и эффекты

### 🛠 Технические возможности
- **⚡ Быстрая загрузка** - оптимизированные изображения и код
- **🔍 SEO-оптимизация** - правильная разметка для поисковых систем
- **🎯 Плавная прокрутка** - навигация по якорным ссылкам
- **📞 Контактная форма** - удобная связь с клиентами

## 🏗️ Структура проекта

```
workford-portfolio/
├── public/                 # Статические файлы
│   ├── images/            # Изображения портфолио
│   ├── icons/             # Иконки и SVG
│   └── prev/          # Превью работ
├── src/
│── Carousel.js      # Карусель портфолио
│── Review.js        # Компонент отзыва
│── ModalWindow.js   # Модальные окна
│── Main.js        # Навигация
│── index.css       # Основные стили
│── Carousel.css       # Стили карусели картинок
│── ModalWindow.css       # Стили модального окна
└── package.json           # Зависимости проекта
```
